# Phase 2 · 判别：主动让利 vs 被动侵蚀

本文件由 SKILL.md 的 Phase 2 加载。**Phase 1 的灯到这里全部作废，从证据重新开始。**

---

## 判别的本质

Phase 1 能证明的只有一件事：**这家公司的毛利率没有随规模扩张而上升。**

这个事实同时兼容两个完全相反的世界：

| | 主动让利（SES） | 被动侵蚀 |
|---|---|---|
| 谁决定了价格 | 公司自己，按内部规则 | 竞争对手，公司被动跟随 |
| 钱从哪来 | 真实的单位成本下降 | 股东资本 / 未来的利润 |
| 结果 | 份额扩大、护城河变深 | 份额勉强守住、护城河变浅 |
| 终局 | 规模到达对手无法企及的位置 | 全行业无人赚钱 |

**六项测试就是为了确定站在哪一边。每项独立取证，不允许用一项推断另一项。**

---

## T1 · 第二条利润腿（否决项）

**问题**：如果商品毛利归零，这家公司还能不能赚钱？

**取证**：找出不依赖商品毛利的利润科目，写出**具体金额与占营业利润的比例**。

| 形态 | 例 |
|---|---|
| 会员费 | Costco：会员费收入体量与营业利润接近同一量级——**这就是它敢把加价率封顶的结构原因** |
| 订阅 | Prime 之于亚马逊零售 |
| 广告 / 抽佣 | 平台型：商品侧让利，货币化在广告位 |
| 浮存金 | 保险型：承保让利，收益在投资端 |

**判定改为分级，不再是一票否决**（2026-08-19 修正，见下）：

| 分级 | 条件 | 含义 |
|---|---|---|
| **强 SES** | 第二条腿占营业利润 **≥30%** | 利润与商品毛利结构性解耦，可以把商品毛利让到近乎为零 |
| **弱 SES** | 无第二条腿，但让利由**确凿的采购/规模成本优势**供给 | 可持续性**完全绑定在"规模第一"这个位置上**，一旦被追上，让利的资金来源即消失 |
| **非 SES** | 既无第二条腿，也无可证实的成本优势 | 让利是促销或被迫降价 |

**⚠ 为什么改**：原文把 T1 写成一票否决——「找不到第二条腿 → 直接判非 SES，后续不必做」。
但 `references/ses-canon.md` 里我自己写的沃尔玛条目说：**沃尔玛没有 Costco 那样纯粹的第二条腿，
它的让利来自采购议价能力本身，仍是 SES，只是更脆弱。**
**两处直接冲突。** 全市场扫描跑出 21 家绿灯时这个矛盾变得致命——
按原 T1，除 Costco 外全部一票否决，而其中不乏薄毛利、规模领先、费用杠杆确凿的分销商。

**改后的用法**：T1 不再终止流程，而是决定**判定的强度与脆弱性描述**。
弱 SES 必须在结论里写明「护城河绑定在规模第一的位置上」，并把「份额是否仍在扩大」列为首要监控项。

## T2 · 让利是自设规则还是被迫反应

**问题**：这条价格线是公司自己划的，还是对手划的？

**取证**（按证据强度排序）：
1. **成文的、公开的、自我施加的上限**——最强证据。
   例：加价率封顶政策，且长期公开重申、无论竞争环境如何都不突破。
2. 长期一致的定价原则表述（EDLP 之类），且能在十年跨度的文件里反复找到同一措辞
3. 只在对手降价后才降价 → **反向证据，指向被动**

**判定**：找不到任何自设规则，且降价时点总是跟随对手 → 强烈指向侵蚀。

## T3 · 营业利润率的稳定性（可量化的硬判别）

**问题**：毛利让出去了，经营利润有没有跟着塌？

**取证**：同窗口的 gross margin 与 operating margin 序列，看**形状不看端点**。

| 形状 | 读法 |
|---|---|
| 毛利缓降 + SG&A 比率同步降 + 营业利润率基本平 | **规模收益被传导** ✓ SES |
| 毛利缓降 + SG&A 比率平 + 营业利润率同步降 | 没有规模收益，只是在被迫降价 ✗ |
| 毛利降 + 营业利润率**上升** | 让利是假的，钱被费用端截留了 ✗ 不是 SES，是普通的运营改善 |
| 两条线某一年同时断崖 | 先查会计口径变更，不要当成经营事实 |

**这是 Phase 2 唯一可以完全用公开财务数据完成的测试，优先做。**

### T3b · 剔除第二条腿后的商品端利润率（2026-08-19 新增，由 COST 判别暴露）

**T3 有一个口径漏洞**：它看的是合并营业利润率。但真 SES 的第二条腿（会员费/订阅）
是**可以、而且往往必须提价**的——它是让利的资金来源。第二条腿提价会把合并营业利润率推高，
让一家纯正的 SES 公司看起来"没有在让利"。

COST 实测：合并营业利润率 3.3% → 3.8%（**上升 0.5pct**），按 T3 原文该扣分。
但拆开看——会员费 53.23 亿占营业利润 **51.3%**，
**剔除会员费后的商品端营业利润率仅 1.87%**（50.60 亿 / 净销售 2,699 亿）。
商品生意几乎在成本价运营，上升的那 0.5pct 全部来自第二条腿。

**修正后的测试**：
```
商品端营业利润率 = (营业利润 − 第二条腿收入) / 商品净销售额
持平或下降  → 让利真实发生在商品端 ✓
持续上升    → 商品端也在提价，让利叙事存疑 ✗
```

**一句话**：**真 SES 不是"不赚更多"，是"不在商品端赚更多"。**
在第二条腿上取价与 SES 完全相容；在商品端取价则不相容。
**T3 与 T3b 必须一起看——只看合并数会把 Costco 判错。**

### T3c · 毛利额增速 ÷ 收入增速（2026-08-19 新增，由 MCK 判别暴露 —— **最强的单一判别器**）

**原有全部测试都建立在「比率」上**（毛利率、营业利润率、SG&A 比率）。
**比率会掩盖一个致命事实：毛利率从 5.2% 降到 3.6% 看起来只是「薄了一点」，
但换算成金额，它意味着毛利额的增速只有收入增速的三分之一。**

```
r = 毛利额 CAGR ÷ 收入 CAGR
r ≈ 1.0   毛利率的下降被量增完全补偿 → 让利换来了真实的规模回报 = SES 飞轮 ✓
r < 0.5   每多做一块钱生意，留下的毛利在稀释 → 让利什么也没换来 = 侵蚀 ✗
```

**实测（2019–2025 窗口）**：

| 标的 | 收入 CAGR | 毛利率 | 毛利额（十亿） | 毛利额 CAGR | **r** | 读法 |
|---|---|---|---|---|---|---|
| CHEF | 17.3% | 24.3→24.2% | 0.4→1.0 | +17.2% | **1.00** | 飞轮 |
| LAD | 19.9% | 15.4→15.2% | 2.0→5.7 | +19.7% | **0.99** | 飞轮 |
| **COST** | 10.3% | 13.0→12.8% | 19.8→35.3 | +10.1% | **0.98** | 飞轮（原型） |
| SYY | 9.0% | 18.7→18.4% | 9.9→15.0 | +8.6% | **0.96** | 飞轮 |
| SMCI | 35.8% | 14.2→11.1% | 0.5→2.4 | +30.3% | 0.85 | 尚可 |
| AMKR | 8.8% | 16.0→14.0% | 0.6→0.9 | +6.3% | 0.72 | 边缘 |
| **MCK** | 9.7% | 5.2→3.6% | 12.0→14.6 | **+3.2%** | **0.33** | **稀释 ✗** |

**这条为什么必须放在 T3 之后立刻跑**：它一条就能把「主动让利」与「行业性通缩」分开，
而这正是 T1–T6 里最难取证的那一步。**率的变化只有配上额的变化才有意义。**

⚠ 判定阈值：r ≥ 0.85 通过；0.5–0.85 存疑，须结合 T4 单位经济学；**r < 0.5 直接判非 SES**。

## T4 · 单位经济学（成本曲线 vs 价格曲线）

**问题**：单位成本下降得比单位价格更快吗？

**取证**：找出这门生意的自然单位——会员、包裹、订单、平米、门店、GMV——
计算每单位的收入与每单位的成本，**看两条曲线的斜率差**。

- 单位成本降幅 > 单位价格降幅 → 让利由真实成本优势供给 ✓
- 单位价格降、单位成本不降 → 让利由利润供给，不可持续 ✗

**⚠ 必须用单位量，不能用总量。** 总收入增长可以纯靠开店/并购堆出来，
那种增长不产生规模经济，也就没有可让之利。

## T5 · 客户侧的回应

**问题**：让利换回来了什么？

**取证**：续费率 / 留存率 / 单客户支出 / 复购频次 / 份额，**要方向不要绝对值**。

- 续费率维持在极高水平且稳中有升、单客户支出上升 → 飞轮在转 ✓
- 份额在涨但留存在降 → 买来的是交易，不是关系 ✗（补贴型增长的典型形态）
- 拿不到留存数据 → 用份额 + 客单价的组合替代，并降低置信度

---

## T6 · 穿越周期的一致性

**问题**：在压力下有没有偷偷把价格拿回来？

**取证**：找出该公司经历的最近一次行业下行期或成本冲击期，看那几个季度的毛利率与管理层表述。

- 压力期毛利率**未**回升、管理层重申让利原则 → **最强的正面证据**
- 压力期毛利率悄悄修复 → 说明让利是可选项，不是原则 ✗

> 顺风时人人慷慨。SES 的稀缺性全部在于逆风时仍然不涨价。

## ⭐ 管理层语言测试（最便宜的高信号检验）

跑完六项后，读最近 4–8 个季度电话会里管理层对毛利率的表述：

| 说法 | 指向 |
|---|---|
| 「这是刻意的」「我们把节省交给客户」「我们不打算改善毛利率」 | SES ✓ |
| **「我们预计毛利率将恢复/改善」** | **最强证伪句** ✗ |
| 「毛利率压力是暂时的」 | 指向被动，公司自己把让利定义成了问题 |
| 完全回避、只谈营业利润率 | 存疑，追问 |

**真 SES 公司不会承诺毛利率恢复，因为恢复不是目标。**
一家公司只要说过「预计毛利率将恢复」，它就在告诉你它认为当前毛利率是不正常的——
这与「主动让利」在逻辑上不相容。

（此项与 `earner` skill 的语气评分同源，可直接复用其电话会取数流程。）

T3 营业利润率稳定  通过/未通过   证据：<两条序列的形状描述>
T4 单位经济学      通过/未通过   证据：<单位、两条曲线斜率>
T5 客户侧回应      通过/未通过   证据：<留存/份额方向>
T6 穿越周期        通过/未通过   证据：<压力期与当期表现>
管理层语言          支持/证伪     引用：<原话>

证伪条件：出现 <具体事实> 则本判定作废

**判定规则**：
- T1 未通过 → 直接「非 SES」，其余不必跑
- T1 通过 且 T3 通过 且（T2 或 T6 至少一项通过）→ 可判「确认」
- 其余组合 → 「存疑」，并写清缺哪一项证据、去哪里补
