# Merlin · Critic 检查单（独立上下文）

> 生成与评审不能同一上下文（CLAUDE.md 硬约束）。Critic 是独立会话/子代理，只评审不改文件。

## 第一步：机械检查（不 record）

```bash
python3 tools/merlin_check.py <报告> --outline <outline.json> --evidence <evidence.jsonl> --pdf <PDF>
python3 tools/report_check.py <报告> --pdf <PDF>
```

有 FAIL → 直接 REWRITE，不用继续评。

## 第二步：五维评分（1–5）

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 痛点命中 | 答字面 | 答到问题本身 | 答到决策与隐含问题，含义段可执行 |
| 搜索广度 | 单一来源 | 2 类来源 | 一手+二手+反证；每 Q ≥1 一手 |
| 专业性 | 无口径 | 有定义/单位/期间 | 可比基准+口径+区间+边界条件 |
| 结构 | 散文 | 结论-依据 | 结论-依据-含义-置信，六题一致 |
| 可核性 | 无来源 | 有来源 | 每条可回溯 pages/原文，页码/引文对得上 |

**门槛**：五维均 ≥3；任一维 <3 → CONDITIONAL，不得直接交付。

## 第三步：抽原文核验（必须，不能只信报告自述）

- 随机抽 **3 条**核心结论，按报告页码到 PDF 原文核对：数字、单位、期间、口径、引文。
- 重点查机械检查抓不到的：**单位错（万/千）、口径混用（同店 vs 全部）、把二手推断写成事实、页码漂移、索引挂名源（只列不引）**。
- evidence.jsonl 的 claim 与 quote 必须匹配；不匹配算可核性硬伤。

## 裁定

- **PASS**：五维 ≥3、抽原文无误、无挂名源/无未标注推断 → 可交付。
- **CONDITIONAL**：核心结构在，但有可定点修复的问题 → 列出必修项（级别+位置+理由）。
- **REWRITE**：答非所问/来源造假/结构崩 → 重写。

## 轮次规则

- 最多两轮；第二轮仍 CONDITIONAL → **停下交用户定**（继续第三轮 / 接受 / 换会话重做），不得自行硬改。
- 裁定落盘 `memory/state/research/<task>/critic_verdict.json`（轮次、五维分、flags、结论）。
