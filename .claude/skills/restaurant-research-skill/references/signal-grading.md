# 信号分级：检索到的说法哪些能用、打几折、哪些领先财报

**何时读**：Phase 1 采集完、写进数据表之前；以及要引用媒体或自媒体给出的门店数、加盟数据、融资、回本周期、热度时。
**和别的文件的分工**：指标怎么定义看 `metric-definitions.md`，证据怎么分档看 `data-schema.md`。本文件只管一件事：**一条说法进表之前，要不要打折**。
**来源**：AIHOT 餐饮版评分标准（`aihot_canyin/industry/prompts/selection-score.md`，2026-09-29 用户审定）里的噪声规则和口径陷阱，外加 profile 1.1j / 1.1r / 1.1s 三次踩坑的教训。

---

## 一、口径陷阱：进表前逐条过一遍

| # | 陷阱 | 怎么查 | 出过的事 |
|---|---|---|---|
| 1 | **指标名跨公司搬** | 这个指标名，能不能指回「这家公司哪份文件的哪一栏」？指不回去，就不属于这家公司 | 把阿里的 CMR 写成海底捞的指标（1.1j） |
| 2 | **门店数没拆自营和加盟** | 凡是用门店数推收入或客流，第一步先拆开；增量主要来自加盟时，收入端的推断不成立 | 海底捞 H1 自营净减 32 家、加盟净增 58 家，客流方向推反（1.1j） |
| 3 | **GMV、流水、终端销售额当成收入** | 平台口径的交易额，以及加盟体系的终端零售额，都不进公司收入表 | — |
| 4 | **时点错位** | 「截至 X 日」的数，先把相关事件按日期排好，窗口外的剔掉 | 绿茶和蚂蚁数科 7/24 才签约，差点被填进 6 月底的栏（1.1r） |
| 5 | **总额和分项加不平** | 同一张表里既列总额又列分项，先自己加一遍；加不平就写明差额去哪了 | 绿茶堂食＋外卖比总额少 0.10 亿（1.1s） |

## 二、要打折的说法

以下说法**可以写进报告当作「品牌自述」或「市场声音」**，但**不能当作经营事实进核心数据表**。如果非用不可，按【二手·媒体】或【品牌口径】标注，并在旁边写明它会往哪个方向偏：

| 说法 | 为什么打折 | 往哪边偏 |
|---|---|---|
| 「签约门店」「在建门店」「已覆盖 X 城」 | 签约不等于开业；覆盖城市数说明不了单店质量 | 偏高 |
| 「万店目标」「三年开 X 家」 | 是路线图，还没兑现 | 偏高 |
| 招商口径：「单店月入 X 万」「X 个月回本」 | 招商材料天然挑最好的店来讲（实际回收期的查法见 `metric-definitions.md`） | 偏高 |
| 排队、爆火、登上热搜、话题播放量 | 热度不等于经营，要同店、翻台或持续销量的数据来佐证 | 方向不定 |
| 付费榜单、评选、峰会发言 | 大多没有新数据 | — |
| 「数亿元融资」、投资方未披露、估值传闻 | 金额和交易是否完成都无法核实 | 偏高 |
| 单店食安或服务投诉（一家店、一条视频） | 要有监管通报、多地同类事件或品牌层面处置，才算系统性问题 | 偏负面 |
| 只有「维持评级、目标价 X」的券商观点 | 没有新事实 | — |

## 三、领先信号：哪些东西会比财报先出现

客户问「接下来会怎样」时，优先去找这几类。它们是这套工具领先财报 1–2 个季度的来源：

| 先出现的信号 | 之后会体现在哪里 | 大致领先多久 |
|---|---|---|
| 加盟政策变化：加盟费、保证金、抽成、区域保护、开放或暂停加盟 | 门店数、加盟占比 | 1–2 个季度 |
| 成规模关店、退出城市、自营转加盟 | 收入、门店数，以及自营和加盟的结构 | 1 个季度 |
| 调价：具体到 SKU、幅度和范围 | 人均、同店 | 当季 |
| 外卖或团购平台的佣金、补贴、配送费规则调整 | 利润率、外卖占比 | 当季到下季 |
| 原材料、租金、人工出现有数字的变化 | 毛利率、门店利润率 | 1–2 个季度 |

**财报发布后，对同一组数字的复述和解读不算领先信号**。它们只能用来确认数字，不能拿来当增量信息写。

**写成判断时**：如果信号给出了门槛数字和验证时点（比如「年底自营门店低于 X 家」），按 CLAUDE.md 的规则登记到 `memory/state/predictions.md`，同时填好把握档。
