# 设计规则

## 通用规则（两种风格共享）

### 内容优先
- **不删减用户的文档内容**。所有原文段落必须出现在输出中。
- 升格是"在原文行做组件替换"，不是"用组件替代原文"。
- 解释模式可以插入额外组件，但不能移除原文段落。

### 布局
- 12 列网格，容器宽 1200px，左右 margin 80px
- 列间距 (gutter) 20px
- 正文内容占 col 2–12（10 列），全宽组件占 col 1–12
- 响应式：≤1024px 回落单列，≤640px 缩小字体和间距

### 字体三级
| 层级 | 用途 |
|------|------|
| 标题字体 | h1, h2, pullquote |
| 正文字体 | p, li, blockquote body |
| 元信息字体 | mono 等宽：标签、编号、caption、chrome、kicker |

### 色彩约束
- 不使用纯白 `#fff` 和纯黑 `#000`
- 每种风格只有一个 accent 色
- 图表用 accent + 灰色交替，不用多彩
- 交叉线/点阵纹理代替彩色区分

### 分割线规则
- 全文最多 2 条粗线（2px）：chrome rule + hero bottom
- section 之间**不加线**，纯靠间距（64px）呼吸
- accent 线仅用在组件内部标记（blockquote 左线）
- 不允许连续两条线相邻出现

### 写作侧（Markdown 作者遵守，渲染器不改写）
- 用全角中文标点，不重复标点（！！、？？），数字用半角。
- 数字与单位之间留空格（10 GB），度数与百分比不留（90%、20°）。
- 全角标点与其他字符之间不加空格。
- 专有名词保持官方大小写（GitHub、iPhone）。
来源：《中文文案排版指北》。

## 杂志风 (Magazine) 专有规则

### 色彩
6 套主题（墨水经典默认，含深色午夜墨），与 PPT、图文卡片相同，见 `references/themes.md`。纸色、文字层级、线条和强调色都来自设计系统，样式表里不写颜色值。

### 字体
- 标题与正文：衬线，西文 Source Serif 4 在前、中文 Noto Serif SC 在后（设置面板可换西文字形）
- 界面文字、表头：Inter + Noto Sans SC
- 元信息：IBM Plex Mono（与 PPT、卡片的杂志风一致）

### 组件风格
- 微圆角 (3px)
- 交叉线纹理填充（highlight 卡片、图表 bar）
- 分割线：1px 细线
- 标签：描边方框

## 瑞士风 (Swiss) 专有规则

### 色彩
纸色 `#fafaf8` 和灰阶在所有主题下不变，只换锚点色：克莱因蓝（默认）、柠檬黄、柠檬绿、安全橙，见 `references/themes.md`。强调色当小字时用加深后的 `--accent-ink`（柠檬黄 → 深金），色块上的文字用 `--accent-on`。

### 字体
- 标题：Inter, weight 200–300（极细体）
- 正文：Inter, 400
- 元信息：JetBrains Mono, weight 500–700

### 组件风格
- **卡片语言**：所有组件用背景色区分，不用边线框
- 直角（0 圆角）
- 章节编号：56px weight-800，极浅色（`--bg-card`），与标题 flex baseline 同行
- highlight：accent 蓝满底色块
- big-number：accent 蓝满底色块 + 白字
- process：灰底卡片列表
- table：黑底白字表头 + 隔行灰底
- 标签：黑底白字实心色块
- hero：全宽底图 + darken 25% + luminosity 混合 + 网格点阵 overlay

### 分割线
- 几乎不用线。唯一可见线：blockquote 左侧 accent 边线
- section 之间、组件之间、表格行间全部**零线**

## 双语文档处理

当 `meta.lang` 设为 `zh` 或 `en` 时：

1. **段落过滤**：渲染器自动检测每行的主要语言，跳过非目标语言的段落
2. **标题提取**：混合标题如 `Squash and Stretch 挤压与拉伸` 自动提取目标语言部分
3. **结构保留**：heading、blockquote、list、HTML 标签等结构性行不受语言过滤影响
4. **升格标注不受影响**：有 `upgradeMap` 记录的行始终渲染

## 图片选择原则

### Hero 底图
- 优先抽象/几何/建筑/自然纹理
- 避免人像、具象场景
- Unsplash 参数：`w=1400&h=600&fit=crop`
- 底图通过 darken + luminosity 处理，原图明暗不太重要

### 解释模式配图
- 与段落内容相关的意象图
- 优先选能传达概念而非具象展示的图
- Unsplash 参数：`w=1040&h=400&fit=crop`
- 不用 AI 生成的图片

## 两种风格是两套版式系统（v0.12）

不只是换字体——杂志风与瑞士风的**网格、轴线、分隔、图注、强调**全部不同：

| 维度 | 杂志风（文学/编辑） | 瑞士风（国际主义排版） |
|---|---|---|
| 轴线 | 居中对称：标题、章节号、图注、金句全部居中 | 严格非对称：左轨 200px + 正文栏 612px（左齐）+ 余白列，一切左齐 |
| 正文 | 衬线正文，行高 1.95（不用首字下沉） | 无衬线常规字重，行高 1.75；标题更细（200–300） |
| 章节 | 两件：“✦✦✦ 04 ✦✦✦”（两侧对称、向外渐小渐淡，无横线）+ 居中衬线标题 | 2px 粗线起节；大号浅灰章节号挂在左轨，与标题**基线对齐** |
| 图片 | 宽 920px 居中，图注左对齐衬线（不用斜体，见下方「图注」） | 从正文栏起点对齐到右边界；图注放左轨，等宽小号大写标签 + 顶部细线 |
| 金句 | 居中、大号引号“、上下细线（中文不用斜体） | 左轨放 QUOTE 标签，正文栏大号细体，顶部粗线 |
| 普通引用 | 正文宽，左侧 1px accent 细线，无底色 | 正文宽，极浅底 + 灰色左线 |
| 表格/图表 | 书籍三线表；图表无底、上下细线、居中标题 | 粗线表头；图表顶部粗线、等宽大写标题 |
| 页头 | 居中大标题 + 副题 + ❦ 花饰 | 顶栏 + 粗线；标签左、元信息右同一行；全幅照片 hero |

规则：
- 章节标题里作者自带的序号（一、/ 第二部分 / 1.）在自动编号时会被渲染器去掉，避免与 01/02 重复。
- 目录抽屉字号 ≥ 正文（17px，行高 1.55）。
- 条形图保持疏朗：行距 ≥ 7px、组间 16px、条间 6px。

- **中日韩文本不用首字下沉（drop cap）**：方块字没有大小写和字母形体差异，单个汉字放大下沉显得突兀，还会打乱首行对齐与避头尾。两种风格都不用。

## v0.16 · 中文阅读与视觉调研落地
- **栏宽**：杂志风正文栏 30 字/行（`--col: 30×1.0625rem` ≈ 510px），瑞士风 32 字/行（≈ 544px）；行高杂志 1.85、瑞士 1.8，两端对齐。正文栏居中，强调媒体比正文宽（不变）。
- **普通引用**＝正文栏宽，上下 1px 细线夹住，正文色、无灰底。杂志风用楷体（LXGW 文楷 / 楷体 / 仿宋回退），瑞士风保持无衬线（瑞士风不加载衬线/楷体）。强调引用（pull quote、大引号）仍走宽栏。
- **图注**：图下左对齐，杂志风 13px 衬线（不用斜体），瑞士风 12px 无衬线；括号外第一个“。/：/——”之前的首句自动加粗当标题。
- **页眉**：杂志风报头居中、上粗下细两条线，标签写成“[ 栏目 ]”（0.7em、字距 .2em）；瑞士风标签左、元信息右，底部全宽 3px 黑线。
- **标题字重**：杂志风“越大越轻”——h1/h2 500、字距 +0.03em；瑞士风 200（不变）。
- **目录**：窄编号列 + `tabular-nums`，不画分隔线。
- **瑞士风直角无阴影**：图、表、图表、嵌入视频、目录面板一律 `border-radius:0; box-shadow:none`。
- **照片头图压字**：标题只放在照片的安静区，不压人脸/主体；按缩到 360px 宽检查可读性。
- 不采纳：首字下沉；“(01)” 括号编号（保留杂志“04 ✦✦✦”、瑞士浅灰悬挂数字）；描边巨型装饰数字；杂志章节整块色底。

## v0.17 · 杂志风收敛
- 报头只留一行：标签 · 作者 · 日期 · 阅读时长，下面一条发丝线；不再有 ARTICLE/FINAL/归藏 PAGE 标签、重复日期、方括号标签。
- **中文永不使用斜体**（浏览器只能做伪斜体）。副题、图注、引用、章节号一律正体；斜体只留给拉丁文（`lang="en"` 的 em/i）。
- 章节号：`✦✦✦ 01 ✦✦✦`，两侧星号向外对称渐小渐淡；整组以页面中轴光学居中，星号与数字垂直居中（inline-flex + align-items:center，tabular-nums）。
