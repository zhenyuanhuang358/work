# 已知失效场景与方法论清单增量

> 由 SKILL.md 在怀疑归因结论过度拟合、或需要更新方法论清单时加载。
> **本文件是 append-only 的活文档**，`Burry 清单` 直接读它。

---

## 第一部分：已知失效场景（显式写出，避免过度拟合）

### F1 · 言行脱节
**历史上多次公开表达宏观悲观但未对应落地仓位。**
→ **归因不能只看发言，必须以持仓变化为主证据。**
→ 当发言与持仓不一致时，**报告必须把这个不一致本身写出来**，而不是选一个信。

### F2 · 不可复制性
**高浓仓位 + 高换手的组合特征，即使复制持仓也不代表复制了他的资金结构和风险承受能力。**
他的资金是「friends and family」性质，赎回压力与机构资金完全不同。
→ **本框架的价值在于理解决策逻辑，不是生成跟单信号。**
→ 任何输出中出现「建议买入/卖出/加仓」即违反边界。

### F3 · Tier 2 数据的结构性局限
2025-11 之后若确无强制披露，则**任何「未披露仓位」都无法证伪**。
newsletter 有订阅付费商业动机，**选择性披露方向明确**。
→ **归因报告需明确「已知」与「未知」的边界，不能用沉默当作证据。**

### F4 · 13F 看不见空头
**「大空头」的空头部位在 13F 上完全不可见。**
→ 任何关于「他在做空什么」的归因，**13F 不是证据来源**。若无 Tier 1 证据，该结论只能进「未知」栏。

### F5 · 期权按名义市值披露
13F 对期权披露的是标的名义市值，不是权利金。
→ **与股票仓位并列排序会严重夸大期权仓位。必须单列，不与股票同表。**
→ 「某期权仓位占组合 20%」这句话在 13F 语境下几乎必然是误读。

### F6 · 季末快照掩盖季中动作
季中建仓再清仓完全不可见，**换手率被系统性低估**。
→ 报告标题措辞必须是「季末持有什么」，**不能写成「这季做了什么」**。

### F7 · 45 天滞后
看到数据时持仓可能已变。
→ 归因结论描述的是**备案期末的状态**，不是当下状态。**报告日期与数据期间必须同时标注。**

### F8 · L1 的必要不充分陷阱
**「我能算出它便宜」≠「他因为便宜才买」。**
全市场同期有几百家同样便宜的公司他没买。
→ **L1 的结论上限是「符合选股标准」，不是「因此他买了」。**

### F9 · 清仓归因的方向性偏差
清仓在 13F 上只表现为「消失」，价值证伪与纪律触发长得一模一样。
**若默认判成证伪，则在基金注销那一季会得出「认错率 100%」的荒谬结论。**
→ 已在 `attribution-framework.md` 中改为「由基金层面事件开关决定」。
→ **⚠ 反向风险同样存在**：若过度使用「纪律触发」这个出口，会系统性低估认错率。
   **认错率统计必须同时给出含/不含基金事件季两个口径。**

### F10 · 后见之明拟合
用「扫描器与实际持仓的重合度」去反向调筛选阈值，会得到一个只能解释过去的筛选器。
→ **`Burry 校验` 只跑一次，结果只作诊断，不作调参依据。**

### F11 · 分位数的样本偏差
分位数只能在有完整 XBRL 数据的样本内算，而缺数据者系统性偏小盘偏便宜。
→ 排除它们会抬高「便宜」的门槛。**缺数据组单列，不参与计算也不剔除。**
→ 元教训：**任何「检测到异常就删掉异常」的修法，都要问「删完之后样本还代表原问题吗」。**

### F12 · 二手源期间错标
媒体转述的持仓/财务数字高发期间错标（本会话已遇三次：海底捞、英伟达、美团）。
→ **必须回到 13F 原文。**
→ 判别法（已验证三次有效）：**用已确认的独立事实去戳二手源，倒推不一致则弃用该来源。**

## 第二部分：方法论清单增量（append-only）

> 归因中出现现有清单未覆盖的新模式时，**先标为待补充项**，不要临场发明规则塞进框架。
> 经过至少两个季度重复出现后，再提升为正式检查项。

### 格式
```
[YYYY-MM-DD] [待补充 / 已转正] 模式名称
  触发场景：
  暂定判据：
  待验证：需要在哪几个季度看到重复出现才转正
```

### 记录

```
[2026-08-28] [待补充] L3 默认判定方向的双向风险校准
  触发场景：建档时发现原规格「清仓默认判证伪」与其声明目的（防止高估认错率）方向相反
  暂定判据：改为由「当季有无基金层面事件」开关决定默认值
  待验证：拿 2025Q4 / 2026Q1 实际数据各跑一遍，确认修正后没有走向另一个极端
          （即把所有清仓都归为纪律触发，从而系统性低估认错率）。
          验证方法：分别用两种默认值跑同一季，比较认错率差异是否超过 20 个百分点。
```

```
[2026-08-28] [待补充] Tier 1 边界的制度性不确定
  触发场景：Scion 注销投顾注册，但 13F 义务由持仓规模而非注册状态触发
  暂定判据：每次运行从 EDGAR submissions 发现最新 13F-HR 期间，不写死日期
  待验证：观察 2025Q4 / 2026Q1 是否出现新的 13F-HR。
          若出现 → Tier 1 边界后移，Tier 2 的适用范围相应收窄，需回溯修订已出报告。
          若连续两季未出现 → 可将「Tier 1 已终结」的置信度从「中」提升到「高」，但仍不写死。
```

```
[2026-08-28] [待补充] dei:EntityCommonStockSharesOutstanding 的 frames 覆盖率不足
  触发场景：首次实跑，数据缺失样本中 shares 一项占 67%（抽样 100/150）。
            已做 5 期回退（CY2026Q2I→CY2025Q2I），缺失率从 88% 降到 65%，但仍是首要瓶颈
  暂定判据：现状照实报告，不为了好看而放宽 REQUIRED
  路径 a 已试（2026-08-30）：加 us-gaap CommonStockSharesOutstanding/SharesIssued 兜底。
          **结果：真实缺失率 65.4% → 65.4%（未变），Stage B 取价 383 → 425，只多救回约 40 家。
          效果有限，说明缺 shares 的主体在两个分类下都不报，不是标签选错的问题。**
  待验证：剩余两条路径——
          b) 对 Stage A 幸存者逐家拉 companyfacts 补 shares（数百次请求，可接受）
             ← 下次优先试这条，因为 a 的失败说明问题在 frames 的横截面覆盖本身，
               而 companyfacts 是逐家全量，不受 frames 的期间对齐限制
          c) 直接用价格 API 返回的市值字段，跳过「股数×价格」这条路
  ⚠ 偏差方向已知：缺 shares 者可能系统性偏向非标准报送人（外国私人发行人、
    新上市、小盘）。这一群体偏便宜，把它们排除会让 10% 分位的「便宜」门槛偏松，
    即当前榜单可能收进了在全样本下进不来的标的。**报告时必须说明这个方向。**
```

```
[2026-08-28] [已转正] 「数据缺失」与「指标不适用」必须分开统计
  触发场景：首两跑把两者混算，得出 88%/72.6% 的缺失率，看上去筛选器不可用
  判据：数据缺失（管道有洞）影响分位数代表性；不适用（EBITDA≤0、金融机构、
        EV≤0、低于市值下限）是指标本身无定义、被正确排除，不构成覆盖率问题
  实测：同一份样本，旧口径 28.9%，新口径 12.9%
  → 已写入脚本与 screener-spec.md，转正
```

```
[2026-08-28] [已转正] 升序排序前必须先排除指标无定义的样本
  触发场景：EV≤0（净现金超市值）时 EV/EBITDA 为负，升序排序把 −5.80、−0.06
            顶到「最便宜」榜首；FCF yield 被近零 EV 分母放大到 4387%
  判据：EV ≤ 0 → 判不适用，不参与排序与分位数计算
  → **这条可推广：任何「越小越好」的比率指标，分母可能变号时，
     排序前必须先做定义域检查。否则最极端的排名位置会被无意义值占据。**
```

```
[2026-08-30] [⭐ 待补充 · 最重要的一条] 筛选器与他实际持仓几乎不重合，缺的维度是「回撤」
  触发场景：首次跑 Burry 校验。重合 **6 / 172**（他 32 期持有过的股票）；
            他最近四期的股票持仓里**只有 LULU 一只**在筛选器榜上
  诊断：不是筛选器坏了，是「便宜」的定义不同——
    · 筛选器找的是**一直便宜**（全市场 EV/EBITDA 最低 10% 分位）：
      DXC、Kohl's、Macy's 这类常年低估值的标的
    · 他买的是**刚变便宜**：MOLINA、UnitedHealth、Estee Lauder、LULU、
      Canada Goose、V F Corp——全是从高位崩下来的知名公司
    · **同样的低倍数，一个是价值陷阱的常态，一个是叙事破裂的瞬间。
      静态估值分位数区分不了这两者。**
  暂定判据：加入**回撤维度**——距 52 周高点/3 年高点的跌幅分位。
            「低估值 + 大回撤」才是他的画像；「低估值 + 无回撤」是价值陷阱。
  待验证：把回撤过滤加进 Stage B，重跑 Burry 校验看重合度是否上升。
          **⚠ 但按 F10，重合度只能作诊断，不能反过来调参——
            若为了提高重合度而反复调回撤阈值，就是后见之明拟合。
            正确做法：先按经济逻辑定阈值（如回撤 >40%），只跑一次校验看结果。**
  另一层原因（非筛选器可修）：他持仓里 11 家是中概股（BABA/JD/PDD/BIDU），
    报 20-F 而非 10-K，XBRL frames 覆盖不全——**这部分 EDGAR 结构性扫不到。**
  → 同时印证 F8：L1 是必要不充分条件。全市场同期几百家同样便宜的他没买。
```

[2026-08-30] [已转正] 13F <value> 字段的单位在 2023-01-03 切换（千美元 → 美元）
  触发场景：写 13F 抓取器时识别。混用会把 2022 及更早的持仓市值低估 1000 倍，
            且不报错、不崩溃——只会让「他历史上仓位很小」这种荒谬结论看起来正常
  判据：按**备案日期**（非报告期）切换单位，2023-01-03 起为美元
  实测验证：2022Q3 $41.3M → 2022Q4 $46.5M，跨边界连续。
            **单位搞错则此处会出现 1000 倍断崖——连续性本身就是最强的验证。**
  → 已写入 burry_13f.py，转正

[2026-08-30] [已转正] 期权名义 ÷ 股票市值比，是 L2 的新观测量
  触发场景：跑通真实数据后发现该比率跨季波动极大，本身携带信息
  实测：2025Q3 期权名义 $1,313.1M / 股票 $68.1M = **19.3×**
        2025Q1 $186.0M / $13.2M = 14.1×｜2023Q4 起多个季度为 0×
  判据：**该比率突然从 0 跳到两位数，说明工具选择发生了质变，
        而这在「持仓笔数」「总市值」上完全看不出来。** 列为 L2 必算项
  ⚠ 但仍受 F5 约束：名义额不是权利金，比率高不等于「仓位大」，
    只等于「用期权表达的方向性敞口占比高」

[2026-08-30] [已转正] 浓仓位阈值实测 25.6%，不是原规格猜的 15%
  触发场景：用 32 期真实 top1 分布算 80% 分位
  实测：25.6%。按 15% 判会把大量常规仓位误判为「浓仓位」，
        使该信号失去区分力（他历史上 top1 中位数就在 17% 附近）
  → 已写入 SKILL.md 启发式 4，转正

[2026-08-28] [待补充] 扫描器覆盖范围与真实选股范围的缺口量化
  触发场景：EDGAR 仅覆盖美股，而他历史上做过波兰、英国、墨西哥小盘股
  暂定判据：每次扫描输出抬头显式声明范围收窄
  待验证：统计其历史持仓中非美股主体的占比，把「收窄程度」从定性说法变成一个数字。
          该数字应写入扫描输出，让使用者知道漏掉的大概是多大一块。

## 第三部分：出报告前的最后一道闸

**以下任一条成立，报告不得交付：**

- [ ] 存在未标 Tier 的归因结论
- [ ] Tier 2 材料被单独用来支撑某条结论
- [ ] L3 清仓归因写在「查基金层面事件」之前
- [ ] 出现「建议买入 / 卖出 / 加仓 / 跟随」字样
- [ ] 「未知」栏为空
- [ ] 认错率只给了一个口径（未区分含/不含基金事件季）
- [ ] 期权仓位与股票仓位在同一张表里按市值排序
- [ ] 标题或结论写成「他这季做了什么」而非「他季末持有什么」
- [ ] 扫描输出静默剔除了数据不完整的公司
- [ ] 临场发明了一条不在清单里的判据（应标为待补充项）
