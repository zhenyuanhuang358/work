# 宏观事件观察：美联储 / CPI / PPI（2026-10-16 用户要求加入）

## 为什么要单独盯

2026-10-14 九月 CPI 偏热 → 当天 VIX +10.5%、VVIX +10.6%，触发加速度条款转黄灯；
利率敏感板块（HOOD −8.5%、SOFI −6.7%）和芯片（INTC −4.6%）同日大跌，INTC 104P 次日跳空到 11.2。
**宏观数据日是卖方最容易被跳空打穿的日子**，必须在开仓前就知道它在不在持有期里。

## 每次扫描必做

1. **列出未来 5 个交易日内的宏观事件**，写进报告「今日风险提示」。
2. **每个候选标注持有期内有哪些事件**（和财报一起列）。
3. 门槛调整：
   - 持有期内有 CPI / PPI / FOMC → 缓冲÷1σ 门槛由 **1.0 提到 1.2**（事件日的波动不在平日 IV 里）。
   - **事件前一个交易日不新开卖方仓位**；存量确认止损条件单已挂好。
   - 利率敏感标的（券商/金融科技 HOOD、SOFI，长久期成长股）在 CPI / FOMC 前一律只观察。

## 数据出来后：搜索与记录

**搜索（发布后 1 小时内）**：
- `CPI [月份] 2026 actual vs expected core`、`美国 [月份] CPI 同比 核心 预期`
- `PPI [月份] 2026 actual vs forecast`
- `FOMC [日期] statement rate decision`、`美联储 [日期] 利率决议 声明 主席 记者会`
- `CME FedWatch probability [下次会议]`（市场对下次加息/降息的定价变化）

**记录进 journal（一行一事件）**：
| 字段 | 内容 |
|---|---|
| 实际 vs 预期 | 如：核心 CPI 环比 0.4% vs 预期 0.3%（偏热） |
| 市场反应 | SPY / QQQ / VIX / 10 年期美债收益率当日变动 |
| 灯色影响 | 有没有触发加速度条款 |
| 对持仓/候选的动作 | 哪些候选取消、哪些存量要处理 |

**判读口径**：
- 通胀偏热 + 收益率上行 → 利率敏感板块与高估值成长股承压，卖 put 往下挪行权价或暂停。
- 美联储鹰派意外（点阵图上移、主席措辞强硬）→ 次日 VIX 期限结构是否转平是关键。
- 数据偏冷 + 加息预期回落（如 10/02 非农 2.9 万）→ 风险偏好回升，但次日不追，等 IV 回落再卖。
