## 规则（每次「今日美股机会」先过这四条，再出新候选）

1. **存量先于新仓**：任何存量违反「单笔止损亏损 ≤ 净值 5%」或已越过止损价 → 本次报告**第一部分只给存量处理方案，不出新候选**，直到用户确认已处理。
   （R4/R5 仍只是提示，profile 1.1t；本条管的是单笔亏损上限这条硬规则。）
2. **持有期硬线**（用平台报价反解的 IV 计算）：
   - 缓冲÷1σ ≥ 1.0 → 持有
   - 0.8 – 1.0 → 减半
   - < 0.8 或期权价 ≥ 2× 收入 → 全平，不等反弹
3. **接货 > 净值时默认用价差**：卖 put 被行权的金额超过净值，默认结构改为牛市看跌价差（买一张更低行权价的 put 封住跳空），裸卖 put 需用户明确要求。
   **⚠ 2026-10-29：盈立没有组合单**，SPY 744/741 被按裸卖收保证金（一万多美元）→ **价差默认不推**。
   分腿（先买后卖）是否按价差计保证金未证实；用户问到客服确认之前，价差只能作为「可执行性未知」的观察项。
5. **可执行性硬过滤（2026-10-29 用户同意；10/31 改口径）**：只推**单腿裸卖 put**，且 **Reg-T 保证金 ≤ 平台「可取现金」**
   （`tools/option_quote.py --bp <可取现金>`，出「⛔保证金」即剔除）。
   **⚠ 不能用「最大购买力」**：那是买股票的杠杆额度（10/30 为 $20,481 ≈ 净资产 3.3 倍）。10/31 用户实测 SPY 744P
   保证金 $14,117 < 最大购买力 $20,481，平台却显示**「可沽空 0 张」**——卖 put 的保证金只能由净资产 / 可取现金（$6,144）覆盖。
   **最终裁判是下单页的「可沽空 N 张」**：N = 0 的不推。
   **这和 profile 1.1t 不冲突**：1.1t 管的是偏好（接货占净值、风控水位、R4/R5）——那些仍然只提示不否决；
   本条管的是「平台收不收这张单」——推一张下不了的单等于没推。
   理由：条件单止损在隔夜跳空时成交价不受控（INTC 10/15 就是从 6.2 跳到 11.2），价差的最大亏损在开仓时就固定了。
4. **事件压力过滤**：近 10 个交易日内有增发、大股东减持、指引下调、监管处罚 → 该标的本次只出「观察」，不出卖方候选。

- 「张数是按『止损亏损 ≤ 净值 5%』算出来的吗？」

两句没得到确认，我写「建议下单」，不写「可以开」。

## 2026-11-05 起的实盘规则（用户选择「按新规则小仓实盘」）

依据：`tools/put_backtest.py` 回放 81 条真实候选，现行「2× 收入止损」每 $1 收入净 −$0.57；加 50% 止盈后 +$0.16（尚未扣买卖报价差与手续费）。
按股价止损（最差 −11.5×）、只在绿灯开仓、拉长到 35 天均无改善，**否决**。证据只覆盖一个月，边做边验证。

6. **每笔只开 1 张**（单腿卖出 put）。
7. **只做买卖报价差 ≤ 中间价 20% 的单**：(卖价 − 买价) ÷ 中间价 ≤ 20%（2026-11-10 用户定；原为 ÷ 买价 ≤ 10%。11/09 实测：z ≥ 1.2 的合约 bid 中位只有 $0.04，换分母救回 0 行，瓶颈在阈值；放到 20% 多出约 7–17 行、每张收入 $8–13，代价是成交更吃报价差）。这里的「价差」是报价差，**不是价差策略**——盈立不支持组合单，一律单腿。数值唯一出处：`tools/option_quote.py` 的 `SPREAD_MAX`。
8. **止盈挂单 + 止损靠正股提醒手动执行**（2026-11-11 用户定 A；原「两张期权条件单」作废——盈立智能条件单只支持股票，不支持期权，FB-20261111-O04）：
   - 止盈：开仓后挂**普通限价买回单**，价格 = 0.5× 收入。
   - 止损：在 App 给**正股设价格提醒**，提醒价由 `gap_stress.stop_alert` 算（IV +10 个点时期权涨到 2× 收入的正股价；若这个价等于现价，说明光 IV 上升就会触发，改用 IV 不变那档并在草稿警示「要盯期权价」。扫描草稿每个候选都写出）；触发后手动看期权卖价，≥ 2× 收入即买回。每次复核持仓重算提醒价。
   - 手动止损买回后立刻撤掉止盈单（残留买回单若成交会变成买入开仓）。
   - 代价（已知并接受）：美股盘中为北京时间深夜，止损有无人值守时段 → 每笔严格 1 张（第 6 条），接受一年最差跳空亏损。

9. **复盘节点**：实盘满 20 个独立簇，用 `tools/put_backtest.py` 扣真实买卖报价差重跑；为负则停。

## 2026-11-05 起卖 call 纳入（用户决定）

10. **卖 call 与卖 put 同一套规则**：只卖**价外** call（行权价在现价上方，z ≥ 1.0；持有期含 CPI/PPI/FOMC/非农时 ≥ 1.2），每笔 1 张，
    买卖报价差 ≤ 中间价 20%（第 7 条），开仓同挂止损（≥ 2× 收入）+ 止盈（≤ 0.5× 收入）两张单腿买回单。
11. **卖 call 的差别**：
    - 怕的是**急涨**：财报、并购传闻、板块拉升、轧空。持有期内有这类事件的标的不卖 call（与 put 侧的财报过滤对称）。
    - **亏损没有上限**；价内 call 可能被提前行权，被行权后账户会变成做空 100 股。所以**绝不卖价内 call**——那不是收权利金，是方向性做空（11/05 HOOD 80C 例）。
    - 证据不足：合成回测卖 call +0.20~+0.29 / $1 收入，但模型两侧同 IV（真实偏斜下价外 call 权利金更低）、样本期急跌多于急涨，均偏向 call。
      实盘与候选一起积累，满 20 簇用真实报价回放。
12. **保证金按 Reg-T 估算 × 1.15 比可取现金**（平台实际比估算高 7–13%）；最终以下单页「可沽空 N 张」为准。

## 2026-11-05 起两项自动排雷（用户决定：分析用于排雷，不用于预测涨跌）

13. **财报**：`earnings_calendar.json`（fetch-options 工作流同步抓，Finnhub 主、yfinance 兜底）。持有期内有财报 → option_quote 标「⛔财报」，不推；
    日历里没有该标的 → 标「⚠ 财报日未核实」，须先核实再推（INTC 记错日期、AMD 未核实被开仓的教训）。
14. **IV ÷ HV30 < 1.1 → 「⛔IV不贵」，不推**：卖方优势来自期权卖贵了；IV 不高于实际波动就是在平价卖保险。
不做：每笔单的美联储路径预测、个股深度估值——成本远高于 10–30 天单的收益，回测中「绿灯过滤」也未改善结果。

## 2026-11-05 起阶梯加码（用户决定：先证明优势，再按证据加张数）

15. **张数不由感觉定，由 `tools/scale_check.py report` 定**。实盘每笔开、平都记进 `memory/state/options-trades.jsonl`
    （开仓：`open`；平仓：`close`，记真实成交价与方式）。每 20 个独立簇为一轮，五项全过才升一阶：
    | 门槛 | 值 |
    |---|---|
    | 样本 | ≥ 20 簇，跨度 ≥ 6 周 |
    | 扣报价差与手续费后每 $1 收入净 | ≥ +0.30 |
    | 最差一笔 | ≥ −2.5 × 收入 |
    | 止损按时成交（≤ 2.5 × 收入；强平算不按时） | ≥ 90% |
    | 入场 IV ÷ HV30 均值 | ≥ 1.2 |
    阶梯：1 张 → 2 张 → 3 张（3 张另需保证金 ≤ 可取现金 50%）。任一轮不达标退一阶；**连续两轮不达标 → 停止卖方**。
    预期上限要说实话：3 张、+0.30 时约 1.5–2%/月。卖权利金在这个账户规模下不能「大幅」赚钱；能放大美元收益的只有时间和本金。

## 2026-11-05 起借鉴大师原则的三条（用户决定）

16. **行业分散**（Tastytrade / 塔勒布）：同一行业同时最多 1 笔。行业分组见 `memory/state/options-screen.json` 的 sectors；
    `scale_check.py open` 会提示同行业冲突。10 月亏损扎堆在半导体与金融科技，一出事就是一串。
17. **基本面反向名单**（段永平 / 伯里）：`options-screen.json` 的 no_sell_put（基本面差、泡沫、增发减持）/ no_sell_call（拥挤、急涨、轧空风险），
    option_quote 标 ⛔基本面。**每月用 buffett-analyst / burry 复核一次**；reviewed 超过 35 天 self_check 点名。
18. **IV 历史分位 + 21 天离场**（Tastytrade）：fetch-options 每次抓链记一条平值 IV（`options_iv_history.jsonl`），满 15 个交易日后
    IV 低于自身历史中位数标 ⛔IV低位；开仓时距到期 ≥ 35 天的单，剩 21 天仍未止盈就平（`scale_check.py open` 打印离场日）。
19. **新仓到期 20–45 天**（2026-11-05 用户定）：11/05 盘中实测 1 周到期的价外 put 权利金只有几毛，$0.01–0.10 的买卖报价差就占收入 13–50%，
    第 7 条（当时口径 ÷ 买价 ≤10%）几乎过不了；2 周以上明显收窄（UBER 11/20 6–10%、WMT 6–10%）。`options_watch.json` 的 `dte: [20, 45]` 让抓链每天自动滚动，
    `option_quote.py` 不给 `--expiry` 就扫窗口内全部到期日。**30–45 天档仍受 tail-risk 期限溢价闸门（VIX3M/VIX ≥ 1.20）**，闸门关时只做 20–29 天；
    ≥35 天开的单按第 18 条剩 21 天离场。代价：持有期必含 CPI / FOMC 之一，缓冲门槛按 macro-events 一律 z ≥ 1.2。
不借：被行权 / 轮动（用户不接货）；买 put 押方向（不是卖方，小账户经不起连续归零）。
