# 四层归因框架 — 完整检查清单与输出模板

> 由 SKILL.md 在 `Burry 归因 <季度>` 时加载。
> 所有阈值都是经验值，作用是把模糊判断变成可复现的规则，不是宣称能预测。

---

## 通用规则

**每条结论的输出格式固定为：**
```
[Layer N] 结论一句话。｜置信度：高/中/低｜数据：Tier 1 / Tier 2 / Tier 1+2 交叉
```

**置信度定义（不要自由发挥）：**

| 置信度 | 条件 |
|---|---|
| **高** | Tier 1 数据直接支持，且不依赖任何未披露信息的假设 |
| **中** | Tier 1 数据支持方向，但关键量级需要估算；或 Tier 1 + Tier 2 交叉一致 |
| **低** | 主要依赖 Tier 2、公开发言，或依赖「他没说什么」这类沉默推断 |

**低置信度结论不得进入报告的结论区，只能进「未知与待验证」栏。**

## Layer 1 · 选股层 — 为什么是这个标的

**输入信号**：新建仓位的行业、估值区间（EV/EBITDA、P/B、FCF yield）、SBC 稀释水平

### 检查清单
- [ ] **绝对便宜而非相对便宜**：不与同行比，直接看估值倍数是否处于**横截面分位数极值区间**（参考 Stage B 的全市场分布）
- [ ] **SBC 稀释水平是否偏低**（2026 年新增的过滤条件）：股权激励费用 / 营收，与全市场中位数比
- [ ] **该行业/资产类别此前是否出现在持仓历史中**
  - 出现过 → **延续逻辑**，归因应指向「同一套标准在新标的上的应用」
  - 未出现过 → **新方向**，必须在报告中单列，并检查 L4 是否有对应的公开表态
- [ ] **是否为特殊情形**（破产重整、分拆、诉讼驱动、资产处置）——若是，估值倍数可能不是主驱动，归因权重应下调

### 输出格式
```
新建仓位 X，[估值指标] 处于全市场 [分位] 分位，判定为选股层驱动。
｜置信度：中｜数据：Tier 1
行业归属：[行业]（该行业此前 [出现过 / 未出现] 于持仓历史）
```

**⚠ 常见误判**：把「我能算出它便宜」当成「他因为便宜才买」。
估值便宜是**必要不充分**条件——全市场同期有几百家同样便宜的公司他没买。
**因此 L1 的结论上限是「符合选股标准」，不是「因此他买了」。** 想再进一步，需要 L2/L4 补充。

## Layer 2 · 仓位构建层 — 为什么是这个大小/工具

### 检查清单
- [ ] **该仓位占组合比例是否越过浓仓位阈值**
  - **阈值不写死。** 取该管理人历史各季持仓集中度分布，用**前 20% 分位**作为「浓仓位」界线，每季重算。
  - 参考量级：历史上约 15% 是常见分界，但**必须用当期历史数据验证后再引用，不得直接采信这个数字**
- [ ] **工具选择**：普通股 / 看涨看跌期权 / CDS / 可转债
  - 股票 → 无明确时间窗口
  - **期权或 CDS → 预期需要较长验证期，且主动选择 define-risk 方式限定损失**
  - ⚠ 13F 对期权的披露是**名义市值**而非权利金，直接把期权名义额与股票仓位并列比较会严重夸大仓位。**必须单列，不与股票同表排序。**
- [ ] **组合整体集中度较上季度提升还是下降**（前 N 大持仓占比、有效持仓数）
  - 提升 = 风险偏好上行或信念集中
  - 下降 = 分散化或撤退中
- [ ] **新建仓位是一次建满还是分批**（需要连续多季 13F 才能判断）

### 输出格式
```
仓位 X 占组合 [%]，处于历史集中度分布的 [分位]，判定为 [浓仓位 / 常规仓位]。
工具为 [股票/期权/CDS]，隐含时间窗口判断为 [短/长]。
组合整体集中度较上季 [提升/下降] [数值]。
｜置信度：高｜数据：Tier 1
```

## Layer 3 · 退出层 — 价值收敛还是纪律触发（最容易误判的一层）

### ⚠ 默认判定由开关决定（对原始规格的修正）

**原规格写「清仓默认判定为价值证伪，除非交叉验证支持纪律触发——这是防止系统性高估他的认错频率」。**
**这条规则与它自己声明的目的方向相反**：默认判成证伪，只会**推高**统计出来的认错率。
尤其在 2025 年 11 月基金注销那一季，所有仓位同时归零，
按原规则会得到「该季认错率 100%」这个明显荒谬的结论。

**修正后的判定流程（先查后判，不是先判后查）：**
```
Step 1  查当季有无基金层面事件（赎回压力 / 清算 / 注销 / 策略调整 / 主体变更）
Step 2  若有 → 默认「纪律/结构性退出」，且该季所有清仓统一按此处理
           除非某标的的价格证据强烈指向证伪（例如清仓前该标的单季跌逾 X% 且无同步的组合层面减仓）
        若无 → 按价格证据判：
           已修复至估值中枢附近 → 价值收敛式退出
           未修复即清仓        → 价值证伪式退出
Step 3  交叉检查同期公开发言中对该标的的表态，作为置信度调节，不作为判定依据
```

### 检查清单
- [ ] **价格较建仓时是否已大幅修复至估值中枢附近** → 倾向「价值收敛式退出」
- [ ] **同期是否存在基金层面事件** → 倾向「纪律/结构性退出」，**不代表逻辑被证伪**
- [ ] **是全仓清空还是部分减仓**：全组合同步归零 ≈ 结构性；单一标的独立归零 ≈ 标的层面判断
- [ ] **交叉检查同期公开发言中对该标的的表态**
- [ ] **该标的清仓后是否在后续季度重新出现**（重新建仓 = 此前是纪律退出的强证据）

### 输出格式
```
清仓 X。当季 [存在 / 不存在] 基金层面事件（[事件描述]）。
建仓至清仓期间价格 [变动]，[已 / 未] 修复至估值中枢。
判定为 [价值收敛 / 价值证伪 / 纪律触发] 式退出。
｜置信度：中｜数据：Tier 1（事件为 Tier 1 备案 / 公开报道）
```

**报告中必须单独统计并披露：本季清仓中，纪律触发型 N 笔、价值收敛型 N 笔、价值证伪型 N 笔。**
**认错率只能用「价值证伪型 ÷ 全部清仓」计算，且必须标注分母是否含基金层面事件季。**

## Layer 4 · 认知层 — 不可直接观测，仅做交叉验证标注

**这一层不产出独立结论，只调节其他三层的置信度。**

### 检查清单
- [ ] **公开发言中是否有「逆价格加仓」表态**
  - 有 → 说明他处于「主动接受短期证伪」模式，**此时的浮亏不构成逻辑失败的证据**
  - 与 L3 联动：若某标的既有逆价格加仓表态、又在后续被清仓，该清仓的证伪含义显著强于常规清仓
- [ ] **Tier 2 阶段的披露是否可能受订阅商业动机影响**
  - Cassandra Unchained 为付费订阅（$39/月，订阅量级约 30 万）
  - **商业动机方向明确：讲得动人的仓位比讲得平淡的仓位更值得写。**
  - → 因此 Tier 2 出现的仓位有**选择性偏差**，未出现的仓位**无法证伪**
- [ ] **是否存在言行脱节**：宏观悲观表态是否对应落地仓位。**不对应时，报告必须写出这个不对应本身。**

### 输出格式
```
认知层标注：[表态内容]（[日期]，[来源]）。
对 Layer [N] 结论的影响：置信度 [上调 / 下调 / 不变]，理由 [一句话]。
｜数据：Tier 2（含商业动机折价）
```

## 季度归因报告输出模板

```
一、数据来源与 Tier 标注
    本季数据 Tier：[1 / 2 / 混合]
    Tier 1 边界：最新 13F-HR 期间 [YYYY-MM-DD]，备案日 [YYYY-MM-DD]
    Tier 2 材料：[条目列表]（含商业动机折价声明）

二、变动总览
    新建 / 加仓 / 减仓 / 清仓 四张表，含标的、市值、占比、环比变动

三、逐条归因
    每条走 Layer 1–4 检查清单，输出「结论 + 置信度 + Tier」

四、本季度与历史模式的偏离点
    列出与既有清单不符的行为，标注是「新模式」还是「数据噪音」

五、已知 vs 未知（不得省略）
    已知：本季可由 Tier 1 直接确认的事实
    未知：因披露制度或数据缺口无法确认的部分
    ⚠ 未知栏为空，说明边界没画清楚，退回重写

六、方法论清单增量
    若出现现有清单未覆盖的新模式 → 标注为待补充项，写入
    references/failure-modes.md 的「方法论清单增量」区
```
