# 配色主题

网页和 PPT、图文卡片共用同一套主题：杂志风 6 套，瑞士风 4 套。主题的全部颜色（纸色、文字层级、线条、强调色在小字 / 大字 / 色块上的用法）都由设计系统按对比度规则算好，内联在 `assets/gz-<风格>.css` 里。

## 指定主题

渲染时用 `--theme <id>`，或在 annotations.json 的 `meta.theme` 里写 id；不写就用该风格的默认主题。读者还可以在页面右下角的设置面板里切换，选择会记在浏览器里。

```bash
node scripts/render.mjs doc.md annotations.json out.html --style magazine --theme forest-ink
```

**不要在 annotations、Markdown 或页面里写颜色值。**

## 用户给了品牌色或 logo 主色

用 `--brand "#4D6BFE"`（或 `meta.brand`）。渲染器会调用 `scripts/gz-theme.mjs` 把颜色收进本风格精调主题的明度 / 彩度区间，生成一套完整的品牌主题作为初始配色，设置面板里也会多出「品牌色」。终端第一行会打印调整了什么；颜色无法达到可读性要求时会说明原因并退回预设主题。

杂志风会把彩度压到 0.12 以内，高饱和的品牌色会变得更克制（例如 #FF2442 → #b75a59）；需要保留鲜艳度时用瑞士风。
