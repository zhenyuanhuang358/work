## E7 · 中概股：同一组标的上的多空完整循环

| 期间 | 持仓形态 |
|---|---|
| 2022Q4–2024Q2 | BABA / JD / BIDU **股票**（做多，持续 7 个季度） |
| **2024Q3** | BABA / JD / BIDU **股票 + PUT 并存** ← **过渡态** |
| 2024Q4 | BABA / BIDU / JD / PDD 股票（多头恢复） |
| **2025Q1** | **股票全清，只剩 BABA/PDD/JD/TCOM/BIDU 的 PUT** ← 完全翻空 |
| **2025Q2** | **JD / BABA 变成 CALL** ← 再度翻多 |

→ **两年内在同一组标的上走完 做多 → 对冲 → 做空 → 做多 的完整循环。**
→ **「股票与 PUT 并存」（2024Q3）是方向翻转的前兆信号，早于完全翻空一个季度。**

## 数据边界（引用本文件任何数字时必须一并声明）

1. **13F 只含美股多头**：不含空头、现金、债券、非美国交易所上市股票。他本人做过波兰、英国、墨西哥小盘股，**全部不可见**。
2. **期权按标的名义市值申报，非权利金**。$9.12 亿的 PLTR PUT 不代表投入 9.12 亿，实际权利金不披露。
3. **季末快照**：季中建仓再清仓完全不可见，换手率被系统性低估。
4. **45 天滞后**：最新一期永远是 45 天前的状态。
5. **边界冻结**：2025-09-30 之后连续 4 期无备案。注销投顾注册 ≠ 13F 义务终止（义务由持仓 >1 亿美元触发），**持仓是否真降至 1 亿以下无法由 13F 判断**。
