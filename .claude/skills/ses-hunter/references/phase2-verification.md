# Phase 2 · 判别：主动让利 vs 被动侵蚀

本文件由 SKILL.md 的 Phase 2 加载。**Phase 1 的灯到这里全部作废，从证据重新开始。**

---

## 判别的本质

Phase 1 能证明的只有一件事：**这家公司的毛利率没有随规模扩张而上升。**

这个事实同时兼容两个完全相反的世界：

| | 主动让利（SES） | 被动侵蚀 |
|---|---|---|
| 谁决定了价格 | 公司自己，按内部规则 | 竞争对手，公司被动跟随 |
| 钱从哪来 | 真实的单位成本下降 | 股东资本 / 未来的利润 |
| 结果 | 份额扩大、护城河变深 | 份额勉强守住、护城河变浅 |
| 终局 | 规模到达对手无法企及的位置 | 全行业无人赚钱 |

**六项测试就是为了确定站在哪一边。每项独立取证，不允许用一项推断另一项。**

---

## T1 · 第二条利润腿（否决项）

**问题**：如果商品毛利归零，这家公司还能不能赚钱？

**取证**：找出不依赖商品毛利的利润科目，写出**具体金额与占营业利润的比例**。

| 形态 | 例 |
|---|---|
| 会员费 | Costco：会员费收入体量与营业利润接近同一量级——**这就是它敢把加价率封顶的结构原因** |
| 订阅 | Prime 之于亚马逊零售 |
| 广告 / 抽佣 | 平台型：商品侧让利，货币化在广告位 |
| 浮存金 | 保险型：承保让利，收益在投资端 |

**判定**：
- 找到且量级足以覆盖营业利润的显著部分 → **通过**
- 只能说出「他们有会员费」但给不出量级 → **未通过，回去取数**
- 根本没有第二条腿 → **直接判非 SES，后续测试不必做**

> 这一项是否决项的理由：没有第二条腿，让利就没有可持续的资金来源，
> 它要么是促销（短期），要么是烧钱（不可持续）。两者都不是 SES。

---

## T2 · 让利是自设规则还是被迫反应

**问题**：这条价格线是公司自己划的，还是对手划的？

**取证**（按证据强度排序）：
1. **成文的、公开的、自我施加的上限**——最强证据。
   例：加价率封顶政策，且长期公开重申、无论竞争环境如何都不突破。
2. 长期一致的定价原则表述（EDLP 之类），且能在十年跨度的文件里反复找到同一措辞
3. 只在对手降价后才降价 → **反向证据，指向被动**

**判定**：找不到任何自设规则，且降价时点总是跟随对手 → 强烈指向侵蚀。

---

## T3 · 营业利润率的稳定性（可量化的硬判别）

**问题**：毛利让出去了，经营利润有没有跟着塌？

**取证**：同窗口的 gross margin 与 operating margin 序列，看**形状不看端点**。

| 形状 | 读法 |
|---|---|
| 毛利缓降 + SG&A 比率同步降 + 营业利润率基本平 | **规模收益被传导** ✓ SES |
| 毛利缓降 + SG&A 比率平 + 营业利润率同步降 | 没有规模收益，只是在被迫降价 ✗ |
| 毛利降 + 营业利润率**上升** | 让利是假的，钱被费用端截留了 ✗ 不是 SES，是普通的运营改善 |
| 两条线某一年同时断崖 | 先查会计口径变更，不要当成经营事实 |

**这是 Phase 2 唯一可以完全用公开财务数据完成的测试，优先做。**

---

## T4 · 单位经济学（成本曲线 vs 价格曲线）

**问题**：单位成本下降得比单位价格更快吗？

**取证**：找出这门生意的自然单位——会员、包裹、订单、平米、门店、GMV——
计算每单位的收入与每单位的成本，**看两条曲线的斜率差**。

- 单位成本降幅 > 单位价格降幅 → 让利由真实成本优势供给 ✓
- 单位价格降、单位成本不降 → 让利由利润供给，不可持续 ✗

**⚠ 必须用单位量，不能用总量。** 总收入增长可以纯靠开店/并购堆出来，
那种增长不产生规模经济，也就没有可让之利。

---

## T5 · 客户侧的回应

**问题**：让利换回来了什么？

**取证**：续费率 / 留存率 / 单客户支出 / 复购频次 / 份额，**要方向不要绝对值**。

- 续费率维持在极高水平且稳中有升、单客户支出上升 → 飞轮在转 ✓
- 份额在涨但留存在降 → 买来的是交易，不是关系 ✗（补贴型增长的典型形态）
- 拿不到留存数据 → 用份额 + 客单价的组合替代，并降低置信度

---

## T6 · 穿越周期的一致性

**问题**：在压力下有没有偷偷把价格拿回来？

**取证**：找出该公司经历的最近一次行业下行期或成本冲击期，看那几个季度的毛利率与管理层表述。

- 压力期毛利率**未**回升、管理层重申让利原则 → **最强的正面证据**
- 压力期毛利率悄悄修复 → 说明让利是可选项，不是原则 ✗

> 顺风时人人慷慨。SES 的稀缺性全部在于逆风时仍然不涨价。

---

## ⭐ 管理层语言测试（最便宜的高信号检验）

跑完六项后，读最近 4–8 个季度电话会里管理层对毛利率的表述：

| 说法 | 指向 |
|---|---|
| 「这是刻意的」「我们把节省交给客户」「我们不打算改善毛利率」 | SES ✓ |
| **「我们预计毛利率将恢复/改善」** | **最强证伪句** ✗ |
| 「毛利率压力是暂时的」 | 指向被动，公司自己把让利定义成了问题 |
| 完全回避、只谈营业利润率 | 存疑，追问 |

**真 SES 公司不会承诺毛利率恢复，因为恢复不是目标。**
一家公司只要说过「预计毛利率将恢复」，它就在告诉你它认为当前毛利率是不正常的——
这与「主动让利」在逻辑上不相容。

（此项与 `earner` skill 的语气评分同源，可直接复用其电话会取数流程。）

## 判定输出格式

```
【SES 判定】<TICKER>  <确认 / 存疑 / 非 SES>   综合置信 X/10

T1 第二条利润腿    通过/未通过   证据：<科目、金额、占比>
T2 自设规则        通过/未通过   证据：<原文表述与出处>
T3 营业利润率稳定  通过/未通过   证据：<两条序列的形状描述>
T4 单位经济学      通过/未通过   证据：<单位、两条曲线斜率>
T5 客户侧回应      通过/未通过   证据：<留存/份额方向>
T6 穿越周期        通过/未通过   证据：<压力期与当期表现>
管理层语言          支持/证伪     引用：<原话>

证伪条件：出现 <具体事实> 则本判定作废
不含估值，不构成买入信号。估值交 buffett-analyst。
```

**判定规则**：
- T1 未通过 → 直接「非 SES」，其余不必跑
- T1 通过 且 T3 通过 且（T2 或 T6 至少一项通过）→ 可判「确认」
- 其余组合 → 「存疑」，并写清缺哪一项证据、去哪里补
