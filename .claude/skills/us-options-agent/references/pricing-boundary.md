# 定价能力边界与锚失效处理

> 由 SKILL.md 在任何涉及期权定价（权利金/PoP/希腊字母/年化）的场景加载。
> **本文件的两条规则都源自 2026-09 的真实事故，不是预防性条款。**

## ⛔ 锚失效期间：模型估值不可用（2026-09-09 SGI 事故后加入）

**判定**：反解 IV 所用锚的 OTM% 与当前 OTM% 相差 **>5pct** → 锚失效。

**失效后必须做的**：
```
估值        标为「不可用，需平台报价」——不得给数字
浮盈/进度   不计算
Δ / PoP     不计算
预登记阈值  **一律挂起**，直到拿到平台价
```

**为什么不能「给个数 + 附警告」**：2026-09-09 SGI 实测——
模型 $0.20 vs 平台 **$0.650**（低估 225%），浮盈 $227 vs 实际 **$48**（高估 373%），
利润进度 73.6% vs 实际 **15.6%**，而阈值 ≤$0.25 实际差 2.6 倍根本没到。
**我每天都写了「锚失效、以平台价为准」，但那个带警告的数字仍然触发了阈值、驱动了「建议平仓」的错误结论。**
→ **下游的阈值比较不读警告标签。让不可用的数字缺席，而不是带着警告出场。**

**错因不止 skew**：OTM 漂移 5.7pct 按 skew 只解释 IV 48-53%（估值约 $0.34），
真实反解 IV 为 **60.3%**（锚 45.4%，+33%）——**剩余部分是标的自身 IV 整体抬升，模型对此完全无感知。**

## ⛔ 定价能力边界：无实测 IV 则不产出任何定价数字（2026-09-09 用户指令）

**用户原话**：「没有实测能力就不要做了，省的出错」。

**触发原因**：两天内两次被平台价打脸——
- SGI 55P：模型 $0.20 / 平台 **$0.650**（低估 225%），据此错误触发平仓阈值
- GM 79P：模型 $0.71 / 平台 **$1.42**（低估 50%），据此错误得出「年化配不上敞口」

**共同错因**：我用**常态波动率**类比估 IV，而窗口内有宏观事件时，
真实 IV 带**事件溢价**（GM 常态 25–30%，实际 42.6%）。**误差方向恒定偏低，且我无法自己发现。**

### 硬性划分

| 我能精确算（继续输出） | 我不能算（**不得输出任何数字**）|
|---|---|
| 缓冲 %（实时价 − 行权价）| 权利金 |
| 接货义务、R3/R4/R5 | 年化收益率 |
| 到期日选择、剩余天数 | PoP |
| 窗口内事件日历（CPI/FOMC/财报）| Δ / Gamma / Theta |
| 财报是否落在到期日之前 | 期间 1σ、缓冲/1σ |
| 组合层面的接货与现金覆盖 | 任何需要 IV 的量 |

### 工作流（改后）

```
无平台报价  → 只输出「结构」：行权价 / 到期日 / 缓冲 / 接货 / R5 / 窗口内事件
              **定价栏一律写「待平台报价」，不给区间、不给估计、不给「仅供参考」**
有平台报价  → 用报价反解 IV → 此后 PoP / Δ / 年化 / 缓冲÷1σ **全部有效**，可用于裁定
```

**⚠ 不得用「IV 区间 28–36%」这类写法绕过本条**——给了区间就等于给了数字，
下游仍会拿中枢去比阈值。**要么有实测，要么留空。**

**⭐ 反解是本 skill 现在唯一合法的定价入口。** 用户给一个链上价，
我把 IV 反解出来，整条分析链就重新可用（GM 案例已验证：$1.42 → IV 42.6% → 全部指标成立）。
