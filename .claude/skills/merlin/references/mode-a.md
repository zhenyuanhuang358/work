# Merlin · 模式 A：访谈作战包

> 适用：给定背景资料，准备一次见面/访谈/尽调会议。产物：`reports/{slug}_Merlin_Brief.html` + PDF。

## 参数提取

| 参数 | 必须 | 说明 |
|------|------|------|
| `COMPANY` | 是 | 公司全名 |
| `PURPOSE` | 是 | 会议目的（投资尽调 / 销售拜访 / 管理层访谈） |
| `background` | 是 | 背景资料（粘贴或文件） |
| `industry` | 否 | 行业 |
| `interviewee` | 否 | 受访者角色 |

背景缺失时问：「请提供公司背景资料（年报、新闻、研报均可粘贴）」。**不要凭空编背景。**

## 执行（五维度）

1. **战略背景**：核心战略、近期重大动作
2. **财务健康**：关键财务指标变化（从背景资料中提取，标口径）
3. **竞争格局**：主要对手、份额变化
4. **风险矩阵**：4–6 个高概率/高影响风险，按概率×影响排序
5. **提问策略**：20–30 个高价值问题，按议题分组；问题必须可被受访者回答（「贵司战略是什么」等于没问）

再提炼 3–5 个中心假设，每个含「假设内容 + 支撑证据 + 验证问题清单」。

## 输出要求

- 4 张 SVG：议题优先矩阵 / 风险热图 / 问题树 / 置信度仪表盘
- 中心假设区块（3–5 条，含证据与验证问题）
- 分组访谈问题清单
- 结论前置：开头先给 3 条「这场会最该问/最该听什么」
- 文末「分析师附注」：假设依据、来源性质、待核实项
- 交付前跑 `python3 tools/merlin_check.py <报告> --pdf <PDF>`（M0–M9）+ `python3 tools/report_check.py <报告> --record`
- Critic 独立上下文评审（`references/critic-checklist.md`），两轮不过停下问用户
