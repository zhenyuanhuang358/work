# 裁定输出模板

> 由 SKILL.md 在出裁定时加载。按 CLAUDE.md 的 hub-and-spoke 规定，格式模板属 spoke 内容。

## 固定输出结构

```
【尾部风险裁定】YYYY-MM-DD
灯色：🟢/🟡/🔴  （置信度：高/中/低——取决于几个指标可用）

指标读数
  VIX期限结构 (VIX/VIX3M)   X.XXX   [正常/警戒/倒挂]  日变化 ±X%
  SKEW                       XXX     [...]              日变化 ±X%
  VVIX                       XXX     [...]              日变化 ±X%
  VIX                        XX.X    [...]              日变化 ±X%
  共振数：X/4

裁定理由：（一句话，说清是哪几个指标共振）

对当前持仓的动作：（读 options-journal 后给具体的）
对新开仓的动作：（能开/减半开/不开）

变灯触发条件：（明确写出什么数值会让灯色改变，便于下次快速判断）
```

## 本模板的两条硬要求

1. **常驻项必须显式写出**，不得静默剔除：
   `SKEW 154.49（已降为观察项 · 近20日 100% 非绿档，不计入共振）`
2. **定价栏无平台报价时留空写「待平台报价」**，不给数字、不给区间、不写「仅供参考」
   （profile 1.1x：给了区间等于给了数字，下游会拿中枢去比阈值）。
