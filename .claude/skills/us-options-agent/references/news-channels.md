# 新闻标注：消息 → 板块 → 卖方方向（2026-11-05 用户要求）

**用途**：每日扫描步骤「新闻标注」时读。只做**标注说明**，不自动否决候选——用户原话是「在后面加以说明、标注」。
否决仍只来自既有规则（灯色、事件前一日、财报、IV、报价差、保证金、基本面名单）。

## 为什么要有它

价格、IV、财报日历都看不见「还没发生但已经在发酵」的事：美伊冲突 → 油价跳空、某位美联储理事放鹰 → 利率敏感股下杀、
政要一句关税 → 中概整体低开。卖方怕的就是这种跳空：持有期越长、缓冲越薄，越该在下单前知道。

## 原料（按可靠度）

1. `news.json`（fetch-options 工作流每次扫描时抓，Finnhub 要闻近 36 小时 + 60 只个股近 3 天，带时间与出处）。
   **先看 `updated_at`，不是今天的就当没有。**
2. **`fed_speak.json`（2026-11-05 起，同一次 fetch-options 产出）——美联储讲话先读它，不再靠 WebSearch**：
   `schedule` 本周 + 下周全部 FOMC 参与者讲话时间（FF 周历）；`board` 理事讲话原文（理事会 RSS）；
   `headlines` 近 2 天讲话人的报道标题（Google News RSS + Finnhub，带出处与时间）；`usd_high` 高影响美国数据（核对 macro-events 日历）。
   鹰 / 鸽按标题写并注出处；持有期内还有谁要讲，从 `schedule` 列出来。
3. WebSearch 只补 fed_speak / news.json 都没有的（搜不到写「未搜到」而不是「无事」）：
   - 地缘与大宗：`Iran Israel US oil price today` / `OPEC` / 当期热点冲突
   - 美联储讲话：只在 fed_speak.json 缺失或 errors 非空时才搜
   - 知名人士与政要：总统 / 财长 / 商务部长关税与制裁表态；知名投资人（如巴菲特、达利欧、伯里、阿克曼）公开发言
4. 只采用**有时间戳 + 有出处**的条目；只有搜索摘要、找不到原文时间的，标「未核实」。

## 标注怎么写

- **报告顶部「今日消息面」**：3–6 条，每条「时间 · 出处 · 一句话 → 影响板块」。没有就写「无影响本次候选的消息」并列出搜过什么。
- **每个候选后面加 📰 一行**：`📰 [消息一句话]（出处 时间）→ 对本单：不利 / 有利 / 中性`。
  - 卖 put：标的可能下跌的消息 = **不利**；卖 call：可能上涨的消息 = **不利**。
  - 不利且消息在持有期内可能继续发酵（冲突未定、讲话后还有数据）时，加一句「缓冲是否够覆盖一次跳空」：
    用 option_quote 的缓冲对比该标的近 20 日最大单日跌（涨）幅。
- 没有相关消息的候选写 `📰 无`——**写出来**，让用户知道查过了，而不是漏了。
- 存量持仓同样标注。

## 不要做的

- 不要因为一条新闻就否决或推荐——要变成规则，先在 journal 里攒案例，满 20 簇复盘时再议。
- 不要把搜索摘要当事实写数字（油价、涨跌幅以 `stock_prices.json` / 期权链为准）。
- 不要登记无门槛、无时点的「消息面判断」到 predictions（CLAUDE.md 铁律 1）。
