# 运行记录模板

复制到 `memory/state/runs/YYYY-MM-DD_<流水线>_<slug>.md`（流水线：research / options / content / earnings）。
**每完成一步立刻打勾并写产物路径**——这份文件是跨会话续跑的唯一依据。

```markdown
# <流水线> · <标的或主题> · YYYY-MM-DD

状态：进行中        <!-- 进行中 / 等用户 / 完成 / 放弃；C10 按此判断 -->
来源：<用户原话一句 / 定时任务名>
借用流水线：否      <!-- 表外业务线借用时写「是：<业务线>」 -->

## 步骤
- [ ] 1 …（按 pipeline spoke 的步骤逐条抄过来）
- [ ] 2 …

## 关卡
- [ ] G1 合规
- [ ] G2 Critic：<裁定 / flags 数 / 第几轮>
- [ ] G3 PDF
- [ ] G4 预测登记：<登记了几条，档位分布>
- [ ] G5 记账：<写了哪些文件>
- [ ] G6 推送：<commit hash>

## 等用户决定
<没有就写「无」；有就写清问题和选项，状态改「等用户」>

## 交付清单
<路径列表>
```
