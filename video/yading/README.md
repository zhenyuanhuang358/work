# 稻城亚丁 · 宣传短片（40 秒竖屏）

插画风格代码动画（非实拍）：剪纸层叠山体、日照金山、牛奶海倒影、彩林落叶、经幡、红草地。
路径＝playbook 第 1 套「零外部视觉素材的代码动画」。分镜与事实来源见 `storyboard.md`。

| 文件 | 作用 |
|---|---|
| `film.html` | 全部画面；`render(t)` 只由 t 决定，随机数全部来自固定种子（mulberry32） |
| `render.py` | 逐帧渲染 → libx264；`--sheet OUT --times a,b,c` 按指定时刻出缩略图 |
| `out/yading_40s.mp4` | 成片 1080×1920 · 30fps · 无音轨（约 2 分钟渲染） |
| `out/contact_sheet.png` | 十帧取样 |

## 画面系统
- 三怙主神山：主峰 + 副峰叠加塑形（仙乃日宽厚带肩、央迈勇尖峭、夏诺多吉双顶嶙峋），fbm 噪声做山脊与雪线
- 阴影面：从峰顶斜向下的锯齿山脊线为界（竖直边界会像被劈开）；雪面加冰沟细线
- 日照金山：雪区内金色渐变自峰顶向下推进
- 湖面：平视透视（压扁椭圆），倒影以水岸线为轴、按 0.72 压缩翻转并逐行加波纹
- 转场：场与场之间 0.3 秒黑场，场景不重叠

## 地理诚实
桑堆红草地在稻城县城西北约 28 公里、不在亚丁景区，看不到三神山 → 该镜背景只画远山。
牛奶海可见央迈勇、冲古寺望仙乃日，均与实际视线一致。
