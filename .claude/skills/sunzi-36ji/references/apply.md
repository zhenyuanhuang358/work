# 局面分析：庙算表与输出格式

## 1. 庙算表（始计第一：五事七计）

逐项填「我 / 对方 / 谁占优」，每项一句证据。证据不足的标「不明」，不要猜。

| 项 | 原文 | 现代问法 | 我 | 对方 | 谁占优 |
|---|---|---|---|---|---|
| 道 | 令民与上同意 | 团队/支持者是否认同我的目标 | | | |
| 天 | 阴阳、寒暑、时制 | 时机、外部环境、周期 | | | |
| 地 | 高下、远近、险易 | 位置、渠道、规则对谁有利 | | | |
| 将 | 智、信、仁、勇、严 | 主事人的能力与信誉 | | | |
| 法 | 曲制、官道、主用 | 制度、流程、资源调度 | | | |
| 主孰有道 | | 上级/老板站谁 | | | |
| 赏罚孰明 | | 谁能给好处、谁能施惩罚 | | | |

**判定**：优势项明显多 → 可打；相当 → 先伐谋伐交，不伐兵；劣势 → 守或避（走为上）。

## 2. 打法选择（谋攻第三）

| 兵力对比 | 原文 | 现代打法 |
|---|---|---|
| 压倒性优势 | 十则围之 | 全面施压，留出口（欲擒故纵） |
| 明显优势 | 五则攻之 | 直接推进 |
| 稍有优势 | 倍则战之 | 正面竞争，但控制消耗 |
| 相当 | 敌则能分之 | 分化对方联盟，避免正面 |
| 劣势 | 少则能守之 | 守住核心，不扩张 |
| 明显劣势 | 不若则能避之 | 退出或转移战场 |

## 3. 输出格式

1. **结论**（一句）：能打 / 能和 / 该避，以及理由中最关键的一项。
2. **庙算摘要**：占优 X 项、劣势 Y 项、不明 Z 项。
3. **战略**（十三篇）：一句话，注明出处篇名。
4. **战术**（三十六计）：1–2 计，每计写原文一句 + 具体动作 + 越线检查结果。
5. **认错线**：出现什么信号就停下或换打法。
6. **不明项**：要补什么信息、找谁补（用间第十三：先知者必取于人）。
