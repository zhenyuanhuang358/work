## 规则（每次「今日美股机会」先过这四条，再出新候选）

1. **存量先于新仓**：任何存量违反「单笔止损亏损 ≤ 净值 5%」或已越过止损价 → 本次报告**第一部分只给存量处理方案，不出新候选**，直到用户确认已处理。
   （R4/R5 仍只是提示，profile 1.1t；本条管的是单笔亏损上限这条硬规则。）
2. **持有期硬线**（用平台报价反解的 IV 计算）：
   - 缓冲÷1σ ≥ 1.0 → 持有
   - 0.8 – 1.0 → 减半
   - < 0.8 或期权价 ≥ 2× 收入 → 全平，不等反弹
3. **接货 > 净值时默认用价差**：卖 put 被行权的金额超过净值，默认结构改为牛市看跌价差（买一张更低行权价的 put 封住跳空），裸卖 put 需用户明确要求。
   理由：条件单止损在隔夜跳空时成交价不受控（INTC 10/15 就是从 6.2 跳到 11.2），价差的最大亏损在开仓时就固定了。
4. **事件压力过滤**：近 10 个交易日内有增发、大股东减持、指引下调、监管处罚 → 该标的本次只出「观察」，不出卖方候选。

## 每次开仓前我必须问的两句

- 「止损条件单挂好了吗？挂在多少？」
- 「张数是按『止损亏损 ≤ 净值 5%』算出来的吗？」

两句没得到确认，我写「建议下单」，不写「可以开」。
