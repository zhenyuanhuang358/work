# 指标定义、阈值与判定规则

本文件由 SKILL.md 的 Step 2/3 加载。**所有阈值都是经验值，不是精确科学**——
它们的作用是把模糊判断变成可复现的规则，而不是宣称能预测市场。

---

## 四个核心指标

### 1. VIX 期限结构（term_structure = VIX / VIX3M）

**它测什么**：市场是在为**眼前**的风险付钱，还是为**远期**的不确定性付钱。

正常市场里远月波动率高于近月（contango，比值 <1），因为远期不确定性更大。
当比值 >1（backwardation，倒挂），意味着**市场认为最危险的时刻就是现在**——这是最可靠的压力信号。

| 读数 | 判定 | 含义 |
|------|------|------|
| < 0.90 | 极度平静 | 远期溢价充足，卖方环境最舒服 |
| 0.90 – 0.95 | 正常 | 常态contango |
| 0.95 – 1.00 | 警戒 | 曲线在走平，压力在积累 |
| **> 1.00** | **倒挂** | **市场在为当下付钱 —— 卖方最危险的信号** |

**为什么把它排第一**：期限结构是四个指标里**最难被单一事件污染**的。SKEW 可能因为某个大单跳动，
VVIX 可能因为VIX期权的技术性因素波动，但期限结构倒挂需要整条曲线的资金共同表态。

---

### 2. CBOE SKEW 指数

**它测什么**：**深度价外看跌期权相对于平值期权有多贵**——直译就是"尾部保护的价格"。
这正是那篇文章里"银行为崩盘看跌期权支付高额溢价"在公开指数上的映射。

基准值 100 = 对数正态分布（无偏斜）。实际长期在 115–145 之间。

| 读数 | 判定 |
|------|------|
| < 130 | 尾部保护便宜，市场不担心 |
| 130 – 140 | 正常区间 |
| 140 – 150 | 警戒：机构在加价买保护 |
| **> 150** | **危险：尾部保护被抢购** |

**⚠️ 重要限制**：SKEW 的预测力在学术上争议很大——历史上多次出现高SKEW后市场继续上涨。
**因此它在本系统里只作为共振指标之一，绝不单独触发红灯。**

---

### 3. VVIX（波动率的波动率）

**它测什么**：VIX 期权本身的隐含波动率 = **买"波动率保险"要花多少钱**。

VVIX 飙升常**领先于** VIX 飙升，因为聪明钱先去买 VIX call 做保护。

| 读数 | 判定 |
|------|------|
| < 90 | 极度平静 |
| 90 – 100 | 正常 |
| 100 – 120 | 警戒 |
| **> 120** | **危险：对冲需求激增** |

---

### 4. VIX（水平值）

老指标，但仍是不可省略的锚。与 us-options-agent 的 VIX 区间表保持一致：

| 读数 | 判定 |
|------|------|
| < 15 | 低波动（注意：权利金也薄） |
| 15 – 20 | 正常 |
| 20 – 25 | 警戒 |
| > 25 | 危险 |

## 派生用法：短端比率 = 事件溢价计价器（2026-08-10 新增）

缓存里的 `short_end_ratio` = **VIX9D / VIX**，此前只作参考，未参与灯色判定。
**8/10 发现它有一个独立且更实用的用途：在重大宏观事件（CPI / NFP / FOMC）前，它直接回答「市场有没有为这个事件定价」。**

| 读数 | 含义 | 对卖方的裁定 |
|------|------|-------------|
| **< 0.85** | 含事件的近端波动率**低于**中端 —— 市场未为事件定价 | **无 IV 溢价可收 → 事件前不开新的卖方仓位，等事件过完再扫** |
| 0.85 – 1.00 | 正常 | 按常规规则执行 |
| **> 1.00** | 近端高于中端 —— 市场在为眼前的事件付钱 | **有溢价可收**，但同时意味着风险被认真定价，需按黄灯规则缩量 |

**为什么这条重要**：卖方赚事件钱的机制是「卖贵的 IV，赚它事件后的塌陷」。
**当短端比率低时，IV 本来就不贵，塌无可塌——等于免费承担事件风险。** 这与「灯色」是两个独立维度：
**灯色管「环境安不安全」，短端比率管「这单值不值得卖」。绿灯 + 低短端比率 = 安全但不划算，应当空仓等待。**

**⚠ 适用范围（2026-08-11 修订，重要）**：本指标**仅适用于「合约期限 ≈ 事件距离」的情形**。

| 你要卖的合约 | 短端比率是否适用 | 该看什么 |
|-------------|----------------|---------|
| **周期权 / ≤2周**，事件在窗口内 | **✅ 决定性** | 短端比率 < 0.85 → 不卖 |
| **5-6 周（30-45天）** | **❌ 期限错配** | **看期限结构斜率 VIX3M / VIX**：>1.15 = 有期限溢价可吃 |

**原因**：一个宏观事件只占 38 天窗口里的 1 天，方差贡献很小；VIX9D 量的是 9 天，与 38 天合约无关。
**2026-08-10 我犯过这个错**：据短端比率 0.833 否决了一个 38 天的候选，理由不成立。
**同日正确的读法**：VIX9D 12.83 → VIX 15.40 → VIX3M 19.02，插值到 38 天约 15.96 > 30 天读数，**期限溢价存在，可以卖**。

**实例（2026-08-10 / 08-11）**：短端比率 0.833 / 0.831，CPI 在 1-2 天后。**若卖周期权 → 否决；卖 Sep18（38天）→ 该指标不适用，改看 VIX3M/VIX = 1.23（有溢价）。**

## 判定流程（严格按序）

### Step A：各指标独立打分

| 分数 | 含义 |
|------|------|
| 0 | 正常或更好 |
| 1 | 警戒区 |
| 2 | 危险区 |

### Step B：加速度检查（原则3的落地）

对每个指标计算变化率：
- **单日变化 > 10%** → 该指标得分 **+1**
- **3日累计变化 > 20%** → 该指标得分 **+1**（与单日规则取较大者，不叠加）

> 缓存只存当前值，日变化需用 `prevClose` 或前一日缓存快照计算。
> **若无法取得历史值，明确标注「加速度未检查」并降低置信度，不要跳过声明。**

### Step C：共振判定

```
总分 = 四个指标得分之和（含加速度加分）
危险指标数 = 得分 ≥2 的指标个数
警戒指标数 = 得分 =1 的指标个数
```

| 灯色 | 条件 |
|------|------|
| 🔴 红灯 | 危险指标数 ≥2  或  总分 ≥5 |
| 🟡 黄灯 | 危险指标数 =1  或  警戒指标数 ≥2  或  总分 3-4 |
| 🟢 绿灯 | 其余 |

**共振是硬要求**：单个指标进入危险区（危险指标数=1）只到黄灯，**不允许直接跳红灯**。
这条规则的目的是防止 SKEW 或 VVIX 的技术性跳动造成假红灯。

## 边界情形处理

| 情形 | 处理 |
|------|------|
| 某指标为 null（拉取失败） | 该指标不计分，**分母相应缩小**，并在输出中标注「X/4 指标可用」+ 置信度降一级 |
| 仅1个指标可用 | **不输出灯色**，只报读数并说明「指标不足以判定，建议人工确认」 |
| 期限结构倒挂但其他三个全绿 | 黄灯（符合共振规则），但在裁定理由里**明确点出倒挂**，因为它是最可靠的单指标 |
| VIX < 15 且全绿 | 绿灯，但附注「权利金偏薄，注意 IV Rank 门槛」——避免用户在低波动期强行开仓 |
| 事件日（FOMC/CPI/财报季高峰） | 灯色不变，但在输出中标注「事件驱动，事件后可能快速回落」 |
